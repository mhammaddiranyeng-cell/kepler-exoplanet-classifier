An engineer equally comfortable wiring a contactor, writing ladder logic, and training a neural network.

RiverExtract

Senior design

AUST · Advised by Dr. Gaby Abou Haidar · Co-advised by Dr. Chafic Saide

A stationary, conveyor-based river waste collection and sorting system — built as a working prototype and specified as a full-scale, solar-powered installation.

Engineering detail

  • Integration: Modbus RTU over RS-485 linking PLC to the IoT layer, MQTT telemetry, YOLOv8 waste classification.
  • App: React PWA monitoring spec — HiveMQ Cloud MQTT, Firebase push, E-Stop, jam recovery, bin-dump control, live AI detection feed and event log.
  • Deliverables: 60-page final report, A1 expo poster, single-page project site, Fusion 360 parametric Python script.

Tiny neural predictors in DPCM

IEEE paper

Cross-domain study — speech & ECG · 8-page IEEEtran

“Tiny Neural Network Predictors in DPCM: A Cross-Domain Study on Speech and ECG with Closed-Loop Stability and Evaluation Pitfalls” — a complete DPCM/ADPCM compression pipeline in Python and PyTorch.

Engineering detail
  • Five tiny neural predictor configurations (≤1500 parameters each) benchmarked against a well-tuned linear baseline.
  • Two domains: the Arabic Speech Commands Dataset and the MIT-BIH Arrhythmia (ECG) Database.
  • Closed-loop stability analysis, plus a catalogue of evaluation pitfalls that inflate reported gains.
  • Finding: no tested tiny network robustly beats the linear baseline under fair multi-slice evaluation — an honest negative result kept in the final paper.
  • PyTorch
  • DSP
  • DPCM/ADPCM
  • ECG

IoT water pump controller

Built

ESP32 + HiveMQ Cloud MQTT

A manual-start, auto-stop pump controller extending the RiverExtract IoT architecture — remote triggering with a stop condition that holds even when the network doesn't.

Engineering detail
  • Latch logic: PumpRun = (RemoteON_cmd OR PumpRun) AND NOT FloatFull.
  • Float switch guarantees auto-stop regardless of connectivity — safety in hardware, not in the cloud.
