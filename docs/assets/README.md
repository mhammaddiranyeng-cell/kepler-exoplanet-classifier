# Assets

## Profile photo

Drop your portrait here as **`profile.jpg`** (square crop works best, ~600×600px):

```
docs/assets/profile.jpg
```

The site loads it automatically. If the file is missing, the portrait circle
falls back to the initials "MD" — so the page never looks broken.

To use a different filename or format, edit the `<img src="./assets/profile.jpg">`
line in `docs/index.html`.
